Embider School Bot

Embider School Bot በኢትዮጵያ ውስጥ ለሚገኙ ማንኛቸውም ትምህርት ቤቶች (አንደኛ እና ሁለተኛ ደረጃ) የተማሪ፣ የወላጅ እና የአስተማሪ ግንኙነትን ዲጂታል ለማድረግ የተሰራ ዘመናዊ የቴሌግራም ቦት ነው። 

ይህ ቦት በትምህርት ቤቶች እና በቤተሰብ መካከል ያለውን የመረጃ ልውውጥ ፈጣን፣ ቀልጣፋ እና ተደራሽ ያደርጋል።

---

## ✨ ዋና ዋና አገልግሎቶች (Features)

* የውጤት መቆጣጠሪያ፦ ተማሪዎች እና ወላጆች የተፈተኑትን ፈተናዎች እና የሪፖርት ካርድ ውጤት በምስጢር ቁጥር ማየት ይችላሉ።
* የእለት ተእለት ማስታወቂያ፦ የትምህርት ቤቱ አስተዳደር የሚልካቸውን አስቸኳይ መልእክቶች እና የወላጅ ስብሰባ ጥሪዎችን ወዲያውኑ ያደርሳል።
* የክፍል ክፍለ-ጊዜ (Schedule)፦ የዕለቱን ወይም የሳምንቱን የትምህርት ክፍለ-ጊዜ (Time Table) ዝርዝር ያሳያል።
* የቤት ስራ እና ምደባ (Assignments)፦ አስተማሪዎች የቤት ስራዎችን እና የማንበቢያ ማቴሪያሎችን (PDF) በቀላሉ ለተማሪዎች የሚያጋሩበት ክፍል አለው።

## 🚀 አጠቃቀም እና አቀናባሪ መመሪያ (Setup & Installation)

ይህንን ቦት በራስዎ ትምህርት ቤት ሰርቨር ላይ ለመጫን የሚከተሉትን ደረጃዎች ይከተሉ፦

### 1. ማከማቻውን ወደ ኮምፒውተርዎ ያውርዱ (Clone)
git clone https://github.com
cd embider-school-bot
### 2. የሚያስፈልጉ ላይብረሪዎችን ይጫኑ (Install Requirements)
pip install -r requirements.txt
### 3. የምስጢር ቁልፎችን ያዘጋጁ (Environment Variables)
በዋናው ፎልደር ውስጥ .env የተባለ ፋይል ፈጥረው የሚከተሉትን ምስጢራዊ ቁልፎች ያስገቡ፦
BOT_TOKEN=የእርስዎ_ቴሌግራም_ቦት_ቶከን
DATABASE_URL=የዳታቤዝ_አድራሻ
### 4. ቦቱን ያስጀምሩ (Run the Bot)
python bot.py
